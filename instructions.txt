1. SYSTEM PREREQUISITES
--------------------------------------------------------------------------------
- Node.js: v18.x or v20.x LTS installed (https://nodejs.org)
- npm: v9.x or higher
- PostgreSQL: v14+ or v16+ running locally or accessible remotely
- Postman or curl (optional, for backend API testing)

2. POSTGRESQL DATABASE INITIALIZATION
--------------------------------------------------------------------------------
Ensure your local PostgreSQL instance is running:
  sudo systemctl start postgresql # Linux (or start via Services on Windows / brew on macOS)

Connect to PostgreSQL and create the database:
  psql -U postgres -c "CREATE DATABASE colcom_biosecurity_db;"

Create a dedicated database user with password:
  psql -U postgres -c "CREATE USER colcom_admin WITH PASSWORD 'colcom_secure_password_2026';"
  psql -U postgres -c "GRANT ALL PRIVILEGES ON DATABASE colcom_biosecurity_db TO colcom_admin;"

Set your DATABASE_URL environment variable in your server configuration or server/.env:
  DATABASE_URL="postgresql://colcom_admin:colcom_secure_password_2026@localhost:5432/colcom_biosecurity_db?schema=public"

4. STEP-BY-STEP LOCAL DEVELOPMENT SETUP
--------------------------------------------------------------------------------

STEP 4.1: INSTALL & MIGRATE BACKEND (server/)
  cd server
  npm install
  npx prisma generate
  npx prisma db push

STEP 4.2: RUN BACKEND DEVELOPMENT SERVER
  npm run dev
  # Server will start on http://localhost:5000 (or port configured in .env)

STEP 4.3: INSTALL & RUN FRONTEND CLIENT (client/)
  In a new terminal window:
  cd client
  npm install
  npm run dev
  # Frontend will start on http://localhost:3000

Alternatively, run in the integrated full-stack single-port mode from workspace root:
  npm install
  npm run dev
  # Integrated applet boots on http://localhost:3000 with Express + Vite middleware

5. PRODUCTION BUILD & DEPLOYMENT WITHOUT DOCKER
--------------------------------------------------------------------------------

STEP 5.1: BUILD CLIENT ASSETS
  cd client
  npm run build
  # Generates optimized static HTML/JS/CSS assets in client/dist/

STEP 5.2: COMPILE SERVER TYPESCRIPT
  cd ../server
  npm run build
  # Compiles TypeScript into server/dist/

STEP 5.3: LAUNCH IN PRODUCTION MODE
  cd ../server
  export NODE_ENV=production
  export PORT=5000
  node dist/index.js
  # Serves the compiled REST API and static React frontend

6. DEFAULT SECURITY CREDENTIALS & INITIAL CONFIGURATION
--------------------------------------------------------------------------------
- Admin Dashboard URL: http://localhost:3000/#admin (or switch view via UI header)
- Default Username: admin
- Default Password: admin
- Toggleable Email MFA: Disabled by default for direct initial login. Can be enabled
  in the Admin Settings tab to enforce 6-digit OTP verification.
- Dynamic Logo: Upload your corporate PNG/JPEG logo in Admin Dashboard -> Settings.
  The logo automatically propagates to the Gate Mobile Scanner, the Admin Header,
  and outbound EOD PDF reports.
- Theme Toggle: Click the Sun/Moon icon in the top header to toggle between
  Light Mode and Dark Mode. The selection persists in localStorage.

7. AUTOMATED EMAIL ALERT & PDF REPORT CONFIGURATION
--------------------------------------------------------------------------------
Configure your corporate SMTP credentials in server/.env or via Admin Dashboard:
  SMTP_HOST="smtp.colcom.co.zw"
  SMTP_PORT=587
  SMTP_USER="security@colcom.co.zw"
  SMTP_PASS="your_smtp_password"
  EMAIL_FROM="no-reply.security@colcom.co.zw"

- Entry Denial Alerts: Fired in real-time to configured security emails when an entry
  triggers African Swine Fever / Foot-and-Mouth Disease biosecurity quarantine rules.
- EOD PDF Report: Automatically compiled at scheduled time (e.g., 18:00) with
  embedded corporate logo, daily metrics, and denial audit breakdowns.
